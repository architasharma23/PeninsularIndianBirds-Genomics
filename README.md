# PeninsularIndianBirds-Genomics
Analytical pipeline for working with low-coverage whole-genomes and UCEs for birds in Peninuslar India

#This section will talk about how to calculate DXY. 
I'm using **ANGSD** for generating **.maf.gz** files. **.maf** files are : per-site allele frequencies generated by the -**doMaf** flag in **ANGSD**.
Intuitively, if each population has 3 samples, 3 x 2 = 6 chromosomes and 6 x 6 = 36 pairs for comparison should be a fair sample size for Dxy calculations. 
I will be adding two bash scripts in the repository and 1 R-code for calculation of DXY. 

**REFERENCE** FOR THIS IS  : [https://github.com/mfumagalli/ngsPopGen/blob/master/scripts/calcDxy.R](url)  **(Penalba script)**
